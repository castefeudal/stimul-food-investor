# STIMUL FOOD — Investor Site

Статический сайт для инвесторов, опубликованный через GitHub Pages.

## Структура

- `index.html` — главная страница
- `assets/` — стили, JavaScript и изображения
- `downloads/` — инвестиционная презентация, бизнес-план и финансовая модель
- `privacy.html` — политика конфиденциальности

## Публикация

GitHub Pages: `https://castefeudal.github.io/stimul-food-investor/`

Сайт не использует Cloudflare и не требует серверной части для просмотра и скачивания материалов.
